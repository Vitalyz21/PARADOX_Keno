# PARADOX KENO

Адаптивная Keno-игра для браузера и Telegram Mini App. Интерфейс в тёмной casino-tech палитре с зелёными и бронзовыми акцентами.

## Функции
- Поле 1–40, выбор от 1 до 10 чисел, случайный выбор и очистка.
- 10 уникальных чисел в каждом розыгрыше.
- Режимы выплат Classic, Low, Medium и High.
- Таблицы множителей Stake Keno как ориентир для виртуальной игровой механики.
- Ставка 0.10–1 000.00 виртуальных USDP, быстрые суммы, уменьшение/увеличение.
- Подсветка совпадений, результат раунда, таблица выплат и история последних 30 игр.
- Серверный розыгрыш через `crypto.randomInt`; SQLite хранит баланс и историю.
- Адаптация для мобильных экранов и Telegram Web App SDK.

## Запуск локально
Требуется Node.js 22 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Загрузка в GitHub
1. Создайте пустой репозиторий GitHub, например `PARADOX_Keno`.
2. Загрузите **все файлы и папку `public`** из этого архива в корень репозитория.
3. Убедитесь, что `server.js`, `package.json` и `render.yaml` находятся в корне.

## Развёртывание на Render
1. В Render выберите **New → Blueprint** и подключите GitHub-репозиторий.
2. Render прочитает `render.yaml`, установит зависимости и запустит приложение.
3. В Blueprint описан Persistent Disk `/var/data` для SQLite.
4. После деплоя проверьте `https://ВАШ-ДОМЕН/api/health` — должен вернуться JSON с `ok: true`.

## Важно
- USDP — только виртуальные игровые кредиты. В проекте нет депозитов, криптокошелька, переводов, обмена или вывода денег.
- Это самостоятельная игра, а не официальный продукт Stake. Таблицы множителей использованы как референс механики и должны быть проверены перед публичным использованием.
- Игровой профиль создаётся в браузере по случайному UUID; это не защищённая учётная запись. Очистка данных браузера создаст новый профиль.
- Перед публичным запуском рекомендуется аудит таблиц выплат, безопасности и нагрузки.
