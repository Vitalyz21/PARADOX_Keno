# PARADOX KENO

Полноценная адаптивная веб-игра Keno с виртуальными игровыми единицами USDP. Дизайн: тёмный casino-tech, Tiffany, зелёный и бронзовый акценты. Интерфейс адаптирован для Android и может быть добавлен на главный экран как веб-приложение.

## Игровая механика
- 40 чисел на поле, расположение 5 рядов × 8 колонок.
- Игрок выбирает от 1 до 10 чисел; сервер случайно выбирает 10 из 40 без повторений.
- Режимы риска: Classic, Low, Medium, High.
- Таблица множителей меняется в зависимости от режима и количества выбранных чисел.
- Ставка 0.10–1 000.00 виртуальных USDP; быстрые суммы, половина и удвоение.
- Анимация последовательного розыгрыша, подсветка выпавших чисел и совпадений, звуковые эффекты по желанию.
- Возможная максимальная выплата, краткая таблица множителей, обратная связь по раунду и история последних 30 игр.
- Начальный баланс 1 000 виртуальных USDP; SQLite сохраняет баланс и историю между посещениями.
- Розыгрыш выполняется на сервере через криптографический генератор Node.js `crypto.randomInt`.

## Запуск локально
Требуется Node.js 22 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Развёртывание на Render
1. Загрузите всё содержимое проекта в корень GitHub-репозитория.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml`, установит зависимости и запустит сервер.
4. Persistent Disk подключается в `/var/data`; база SQLite сохраняется при перезапусках.

## Важные ограничения
- USDP здесь — исключительно виртуальные игровые единицы. Нет депозитов, криптокошельков, переводов, обмена или вывода средств.
- Идентификатор игрока хранится в браузере. Это локальный игровой профиль, а не защищённая учётная запись с паролем.
- Множители — демонстрационная таблица для этой игры, не заявление о точном воспроизведении выплат какого-либо другого казино.
- Перед публичным запуском рекомендуется нагрузочное тестирование и отдельный аудит механики/таблиц выплат.


## Бесплатный запуск на Render

В этой версии `render.yaml` использует тариф `free` и временную базу SQLite в `/tmp`. Бесплатный Render не поддерживает постоянные диски: база и игровой баланс могут сбрасываться после перезапуска, сна или нового деплоя. Бесплатный сервис также засыпает после 15 минут без трафика и может запускаться около минуты при следующем посещении. Эта конфигурация подходит для тестирования, не для хранения важных данных.
